# -Mouse-

Open [`[Mouse] PCB.kicad_pro`](%5BMouse%5D%20PCB.kicad_pro) from this checkout in KiCad 10. The project contains the mouse schematic and an empty PCB file ready for layout. Commit updates to the `.kicad_sch`, `.kicad_pcb`, and `.kicad_pro` files together when a change spans them.

The project library tables load the custom symbols and footprints from this checkout. The optional STEP models referenced through `MYLIB_DIR` and `AMZPATH` require local model libraries for the 3D view.

The XIAO nRF52840 Plus symbol and footprint come from Seeed Studio's Open Parts Library under CC BY-SA 4.0. The symbol library has been reduced to the entry used by this project.
